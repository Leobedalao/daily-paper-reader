Abstract. Accurate lung tumor segmentation in computed tomography (CT) is essential for treatment planning, response assessment, and quan-titative imaging analysis. However, 3D lung tumor segmentation remains challenging because tumors occupy only a small portion of the whole vol-ume and exhibit heterogeneous appearances across anatomical locations. In patch-based training and sliding-window inference for 3D medical im-age segmentation, location-dependent heterogeneity is further amplified because cropped image patches provide limited global anatomical con-text, making it difficult for a model to adapt its feature processing ac-cording to the anatomical region from which each patch is extracted. To address this limitation, we propose an Anatomical Prior-guided Routing Module (APRM) for lung tumor segmentation. For each image patch, we obtain anatomical prior information of regional occupancy and de-terministically select an anatomical routing gate. The selected gate then performs sparse feature routing over a shared expert adapter pool, en-abling anatomy-specific feature adaptation while sharing expert capacity across regions. We evaluate APRM on two datasets with various back-bone networks and demonstrate consistent improvements over baseline models. Furthermore, feature visualizations show that APRM produces different feature responses depending on patch location, indicating that the proposed routing mechanism effectively adapts feature processing according to anatomical context. 

Keywords: Computed Tomography · 3D Medical Image Segmentation · Anatomical Prior-guided Routing

Mixture-of-experts (MoE) methods perform dynamic routing according to input features, activating only a subset of experts for each input while increas-ing the overall model capacity [10, 51]. This conditional computation has been used to scale the number of parameters while keeping the number of activated parameters nearly fixed, leading to improved performance and efficiency [10]. Distribution-aware MoE (dMoE) interprets MoE from a control-theoretic per-spective as a feedback control that flexibly adapts to heterogeneous medical image data distributions [43]. However, instead of relying only on feature-driven routing, prior knowledge can provide a meaningful control signal by changing the routing strategy according to the anatomical location. ## 2 Related Work 

2.1 Medical Image Segmentation 

Medical image segmentation aims to classify regions of interest, such as lesions, organs, and tumors, at the pixel or voxel level [19, 22, 24, 26–29, 49]. This task is important for diagnosis, treatment planning, surgical guidance, and quantitative analysis. U-Net [47] uses an encoder–decoder structure with skip connections, which is effective for voxel-wise prediction [5, 40, 47]. Many U-shaped variants have been proposed to improve this structure. ResUNet adds residual connec-tions to convolution blocks for training deeper networks [7]. The nnU-Net instead uses a basic U-Net and automatically adapts preprocessing, training settings, and network configuration to each dataset [15]. Transformer-based methods have also been studied to capture wider context. UNETR uses a transformer encoder with a convolutional decoder [12], and SwinUNETR uses a hierarchical Swin Transformer [11]. Since full-resolution 3D volumes require large memory, these methods usually use patch-based training and sliding-window inference [15, 17]. Recent methods also improve U-Net with modern convolution blocks or large-scale pre-training, such as MedNeXt [48] and STUNet [14]. Unlike these works, APRM does not introduce a new backbone. It is a plug-in routing module that can be added to existing segmentation models. 

2.2 Anatomical Priors and Mixture-of-Experts 

Anatomical priors provide information about body structures and have been used as spatial maps, shape constraints, auxiliary inputs, or post-processing steps in medical image segmentation [13, 31, 36, 54]. Automatic CT parsers such as TotalSegmentator can extract organ masks from CT images [53]. These masks can provide anatomical context for tasks such as lymph-node segmentation [8, 38]. MoE models use conditional computation. A router selects a small number of experts for each token or patch, so the model can increase its capacity without using all experts at once [10,46,51,55]. Recent medical imaging studies have used MoE for continual learning, multi-modal representation, SAM adaptation, and semi-supervised learning [4, 18, 35]. These methods usually use image features, modalities, or prompts for routing. However, feature-based routing methods may overlook anatomical location. In lung tumor segmentation, errors often depend on anatomical location because nearby structures such as the pleura, vessels, and mediastinum can obscure tumor boundaries. We use anatomical priors as the routing context. This allows the model to adapt patch-level features according to the location of each patch. ## 3 Method 

We propose APRM, which adapts feature processing according to anatomical locations to reflect tumor heterogeneity. APRM is added to all scales of the backbone encoder and applies different feature routing strategies according to the anatomical location of each patch. Fig. 3 provides an overview of APRM. Let input image  I ∈ RH×W ×D denote a CT volume, where  H, W , and  D are the spatial dimensions. Let  ω ∈ Rh×w×d denote a patch. The image is divided into patches. We define the patch set  Ω as 

Ω = ω | ω ⊂ { 1, . . . , H } × { 1, . . . , W } × { 1, . . . , D }, ω ∈ Rh×w×d , (1) where patch  ω ∈ Ω denotes a patch region. The local image patch extracted from a patch region  ω is denoted by  Iω . We use an anatomical label map  A extracted using TotalSegmentator [53]. We compute the occupancy ratio of anatomical re-gions in  Iω from  A for routing gate selection. If the outside proportion exceeds a threshold  τout , the patch is assigned to the outside gate. Otherwise, the anatom-ical gate is selected from among the five lung lobes and the central region. The selected gates independently route features to the shared experts. This design allows routing to vary according to anatomical context while enabling expert capacity to be shared across multiple anatomical regions.

3.4 Sampling Process 

During training, a cropped region (i.e., patch)  ω is sampled from the input vol-ume  I, and the corresponding image patch  Iω and anatomical patch  Aω are ex-tracted together. The anatomical patch is used to determine the routing gate ac-cording to Eq. (4). The anatomical prior used for routing is spatially aligned with the feature tokens processed by APRM at each encoder stage. During sampling, we process the full volume using sliding-window inference with an overlap ratio of 0.5 along each spatial dimension. Predictions from overlapping windows are combined using Gaussian-weighted voxel-wise aggregation, following the stan-dard nnU-Net inference procedure. For each patch, the same crop is applied to the anatomical label map and the patch-level anatomical occupancy is computed to select the corresponding anatomical gate. Predictions from overlapping win-dows are aggregated in the original image space and the final segmentation is obtained from the merged probability map.

## 5 Discussion 

We proposed APRM to incorporate anatomical priors into patch-based 3D lung tumor segmentation. By selecting an anatomical gate for each patch and rout-ing features through a shared expert pool, APRM enables location-aware fea-ture adaptation without assigning separate experts to each anatomical region. The experimental results show that APRM consistently improves segmentation performance across multiple backbones on the NSCLC dataset and also gener-alizes to the external MSD dataset. Compared with a standard MoE module, APRM provides more stable gains, indicating that anatomical context is useful beyond simply increasing model capacity. The ablation and visualization results further show that sparse routing with shared experts learns different feature responses for different anatomical regions, helping the model capture tumor in-teriors, boundaries, and location-dependent heterogeneity. 

Limitations. The proposed method depends on anatomical masks extracted by a pretrained segmentation model. Although this makes APRM practical be-cause it does not require manual anatomical annotation, errors in the anatomical masks may lead to incorrect gate assignment, especially near lobe boundaries, mediastinal structures, or abnormal anatomy. The anatomical categories used in this work are defined at a relatively coarse level, including lung lobes, the cen-tral region, and an outside region. Finer anatomical subdivisions or vessel- and airway-aware priors may provide additional context for tumors with complex local interactions, but they may also increase routing ambiguity and computa-tional cost. The current framework uses deterministic patch-level gate selection based on anatomical occupancy. This improves stability and interpretability, but it may be suboptimal for patches containing multiple relevant anatomical struc-tures. Future work could explore soft anatomical routing, uncertainty-aware gate assignment, or joint optimization of anatomical priors and tumor segmentation.

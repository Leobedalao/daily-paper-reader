## ABSTRACT 

Current state-of-the-art segmentation models still produce anatomically implausi-ble shapes, such as broken vessels and fragmented glands, on the structures that are hardest to segment. Learned shape representations capture what structures look like and can help correct these errors, but most cover a fixed set of anatom-ical classes. Extending this coverage across classes and imaging modalities is costly because it often requires new voxel-level annotations. We propose Diffu-sion for Anatomical Reshaping with Text (DART), which learns a shared shape representation from segmentation probabilities. It uses anatomical descriptions to correct these probabilities without receiving medical images. Across 13 public benchmarks, absolute Dice gains reach 31% for individual gallbladder cases in CT and 10% for individual prostate cases in MRI. Using existing segmentation pre-dictions, we scale a single shape representation from 50 to 377 anatomical classes without new voxel-level annotations for correction training. The shared represen-tation also corrects four lesion classes absent from training and transfers from CT to MRI without retraining. Corrected labels also improve segmentation models, raising one model’s Dice from 57 .1% to 67 .5% . The same pipeline supports anno-tations for 45 ,000 CT scans. These results suggest that sharing shape information within and across classes can reduce the need for new voxel-level annotations when extending segmentation to more anatomical classes and imaging modalities. The model is available at https://huggingface.co/Koushik45/DART-Seg. 

## 1 INTRODUCTION 

Anatomical shape provides reusable knowledge for medical image segmentation. Conventional multi-class segmentation models learn from voxel-level annotations, and extending them to more classes or imaging modalities often requires additional annotations (Li et al., 2024; Bassi et al., 2025a). Even with this supervision, thin vessels, small glands, and hollow organs remain difficult (Figure 1). Their masks can contain broken vessels or fragmented glands, even when much of the anatomy is correctly located. However, learned shape representations used for segmentation correc-tion usually cover one anatomy or a fixed class set (Larrazabal et al., 2020; Painchaud et al., 2020), limiting the reuse of existing annotations. We therefore ask: can a shared shape representation make these annotations useful across patients, anatomical classes, and imaging modalities? We hypothesize that shape similarities within and across anatomical classes allow knowledge learned by existing segmentation models to support correction beyond their original training ex-amples. Within a class, recurring geometry lets predictions for some patients guide correction in other patients. Across classes, anatomical descriptions let one model share common shape features. This reuses anatomical knowledge expressed in segmentation probabilities, without directly relying on image appearance. This reuse offers a way to reduce the need for new voxel-level annotations as anatomical and modality coverage expands. To test this hypothesis, we propose Diffusion for Anatomical Reshaping with Text (DART), a single 3D diffusion model that learns from segmentation probabilities for 377 anatomical classes. Given

## 2 RELATED WORK 

Shape representations for segmentation. Rule-based postprocessing, such as hole filling, mor-phological closing and keeping the largest connected component, is fast but applies the same rule to every structure (Soille, 2004; Serra, 1983; He et al., 2009); organ-specific rule sets narrow this gap but must be written by hand for each class (Liu et al., 2025). Statistical shape models project a mask onto a linear space of training shapes (Cootes et al., 1995; Rogers & Graham, 2002). Learned models are more flexible: anatomically constrained models add a learned shape code to the training loss (Oktay et al., 2018a), Post-DAE maps an implausible mask to a plausible one with a denoising autoencoder (Larrazabal et al., 2020), Painchaud et al. (2020) map a cardiac mask to the nearest valid shape in a latent space, and implicit shape models learn shape manifolds or templates end to end (Raju et al., 2022; Yang et al., 2022b). Neural Annotation Refinement improves adrenal gland annotations (Yang et al., 2022a), and template-guided reconstruction shows that anatomical plausi-bility matters beyond voxel overlap (Xie et al., 2025). Each of these models covers one anatomy, such as the pancreas (Yao et al., 2022), or a fixed set of anatomical classes. SegRefiner adjusts predicted segmentation masks with a discrete diffusion process but does not know which structure it is adjusting (Wang et al., 2023), and in natural images CascadePSP and SegFix sharpen mask boundaries using the image (Cheng et al., 2020; Yuan et al., 2020). DART is a single model that knows which class it is correcting, because a description names it, and it needs no image. Quality-estimation methods score a mask without reference annotations rather than correcting it (Cosarinsky et al., 2026; Galati & Zuluaga, 2021; Wang et al., 2020a; Chen et al., 2026). 

Diffusion models in medical segmentation. Denoising diffusion models learn to reverse a grad-ual noising process (Ho et al., 2020), and conditioning steers one model toward different outputs (Dhariwal & Nichol, 2021). In medical imaging they are mostly used to predict segmentation masks from images (Wu et al., 2024; Bieder et al., 2024; Xing et al., 2023), or to generate images from text (Li et al., 2026). SDEdit edits an input by partially noising and then denoising it (Meng et al., 2022), and diffusion models can reuse learned distributions in other inference problems (Graikos et al., 2022). DART applies this idea to segmentation probabilities. 

Text-prompted and universal segmentation. TotalSegmentator segments more than one hundred structures from CT (Wasserthal et al., 2023), and nnU-Net remains a strong default (Isensee et al., 2021). The CLIP-Driven Universal Model, SegVol, SAT and VoxTell segment many structures from text prompts (Liu et al., 2023; 2024; Du et al., 2024; Zhao et al., 2025; Rokuss et al., 2026), and SAM and MedSAM made promptable segmentation widely available (Kirillov et al., 2023; Ma et al., 2024a). DART borrows the text interface but does not segment images: it corrects the segmentation probabilities that such models predict, and its corrected masks can serve as their training labels. 3Preprint

## 3 METHOD 

DART learns from and corrects segmentation probabilities predicted by segmentation models. For a class named by a description s, its input is a probability map p ∈ [0 , 1] H×W ×D , where pv is the predicted probability that voxel v belongs to the class. It has three parts (Figure 2): a conditioning path that turns s into a vector, a 3D diffusion model that learns a shape representation from proba-bility maps, and a partial noising procedure that corrects p. Probability values preserve information that a binary input would discard: a value of 0.4, for example, would otherwise become background after thresholding at 0.5.3.1 CONDITIONING ON ANATOMICAL DESCRIPTIONS 

Each anatomical class is identified by a description of its name, shape, and location, for example 

“colon, long convoluted haustrated hollow tube, framing the peripheral abdomen from cecum to sigmoid” . Descriptions are drafted by a large language model from standard anatomy references and reviewed by the authors (Appendix O). A frozen text encoder E, all-MiniLM-L6-v2 (Reimers & Gurevych, 2019; Wang et al., 2020b), maps s to a 384-dimensional embedding, and a trainable projection g maps that embedding to a conditioning vector, 

c = g(E(s)) ∈ Rd, g : Linear(384 , 128) → SiLU → Linear(128 , d ), (1) where d is the width of the U-Net timestep embedding. The timestep embedding τt and c are summed, h = τt + c, and h is injected into every residual block as a per-channel offset. We use a text encoder rather than an integer embedding table for two reasons. An index table has no entry for a class outside its training vocabulary, and its entries carry no information about how structures relate. A text encoder can encode descriptions of classes absent from training and represent rela-tionships between descriptions. Because the crop removes absolute position and the model sees no neighbouring structures, location words cannot place a structure in the body; they act only through 4Preprint the embedding, where they make the descriptions of nearby structures similar. At inference, we form a localization mask mv = 1[pv > 0.5] and compute its bounding box with the same fixed margin. Thresholding determines only this rough location. We Crop and resize the original probability map p to obtain xin 0 , retaining values below 0.5 inside the crop. If the local-ization mask is empty, we return an empty segmentation mask. DART also receives the anatomical description and noise level t∗; it receives no medical image, reference annotation, or bounding-box prompt. The denoised estimate is resampled to the native geometry and thresholded at 0.5 to obtain the corrected segmentation mask ˆm (Algorithm 1, Ap-pendix K). A small t∗ allows limited changes, while a larger t∗ allows larger shape changes at the cost of fidelity to the input. 

Choosing t∗. The noise level t∗ is the only hyperparameter specific to DART. It is selected once per class on a validation split from {50 , 150 , . . . , 650 } and then held fixed for every test case and every experiment in this paper, including the transfer experiments (Figure 11). The selected values follow anatomy: compact solid organs take the least noise, glands and hollow organs more, and vessels and muscles the most. For a class absent from the training vocabulary, such as a lesion, t∗ is copied from the structure in which it occurs, for example the hippocampus for a hippocampal tumor. No labels from a test task are used to choose t∗. The same values work unchanged on segmentation probabilities from every segmentation model we test (Appendix D), which suggests that t∗ reflects the shape of a structure rather than the errors of one segmentation model.

Input predictions. DART receives the probability map predicted by a segmentation model, never the medical image. On CT, three automatic segmentation models predict without bounding-box prompts: TotalSegmentator (Wasserthal et al., 2023), AtlasNet (Bassi et al., 2025c; Li et al., 2024) and WholeBodySeg (Cardoso et al., 2022). MedSAM (Ma et al., 2024a), prompted slice by slice with bounding boxes from the reference annotation, places every structure in the right location and so isolates shape. On MRI we use MedSAM and TotalSegmentator MRI (Akinci D’Antonoli et al., 2025). 

Metrics. Dice, IoU, clDice (centerline overlap, which reflects connectivity) and NSD (boundary agreement within 2 mm) are measured against the reference annotation on a 0–100 scale, and their changes are absolute points; HD95 is the 95 th-percentile Hausdorff distance in mm. “Up to” denotes the largest per-case gain unless stated otherwise (Appendix B). 

Baselines. Every correction method starts from the same upstream predictions (DART from the probability map, the others from its thresholded mask) and is tuned per class on the validation split, as t∗ is for DART. On the TotalSegmentator benchmark we compare the eleven baselines of Table 1: four rules, two statistical shape models, two methods that read the image, and three learned correction methods trained on predictions paired with reference annotations: Post-DAE, SegRefiner and a single-pass U-Net with DART’s backbone but no diffusion. The external benchmarks add further methods and the identity control (Appendix M).

## 6 DISCUSSION 

Where DART helps most. The gain follows the room the input leaves. With automatic segmenta-tion models, it falls as the input improves (Spearman ρ = −0.89 and −0.68 ; Appendix D), and in Appendix C it ranges from 8.2 points on an input of 74 .1 to 0.4 on an input above 94 . In the con-trolled comparison, the largest gains fall on elongated structures and small glands, whereas the portal vein, pulmonary vessels and colon gain under 1 point, consistent with the low ceiling of vessels in Figure 5b. 

Limitations and future work. DART works inside the bounding box of its thresholded input plus a fixed margin, so it cannot recover anatomy missing from that crop, and its shape representation can inherit errors of the source models. Stronger departures from typical shape than tumor-bearing kidneys remain untested; the change 1 − Dice( m, ˆm) between the thresholded input mask m and the corrected mask ˆm can flag such cases for review without reference annotations. Other imaging modalities, and combining the shape representation with image features, remain to be explored. 

## 7 CONCLUSION 

DART, a single text-conditioned 3D diffusion model, learns one shared shape representation for 

377 anatomical classes from predicted segmentation probabilities. Without receiving the image, it corrects predictions from automatic and prompted segmentation models across 13 public bench-marks, transfers from CT to MRI and to four unseen lesion classes without retraining, and produces corrected labels that train better segmentation models. This work uses only publicly available, de-identified CT, CBCT and MRI datasets, each accessed under its published license, and no new data were collected from human subjects. ## A TRAINING DATA 

The diffusion model is trained on segmentation probabilities predicted for 3,066 volumes from eight public datasets (Figure 6). Each training example is a probability map for one anatomical class in one volume. The source datasets’ voxel-level annotations define the class inventory; they are not the clean diffusion samples. TotalSegmentator (Wasserthal et al., 2023) contributes 1,228 CT volumes (mean age 63.6, range 18 to 97, 41.2% female). DAP-Atlas (Jaus et al., 2023) contributes 533 CT volumes. AMOS22 (Ji et al., 2022) contributes its 500 CT volumes (mean age 53.6, range 14 to 94, 37.2% female). ToothFairy (Bolelli et al., 2024), in its ToothFairy3 release, contributes 443 CBCT and CT volumes. WORD (Luo et al., 2021) contributes 150 CT volumes (mean age 49.0, range 26 to 78, 41.3% female). SegRap2023 (Luo et al., 2025) contributes 120 CT volumes, TopBrain (Yang et al., 2026) 50 CT angiography volumes, and HaN-Seg (Podobnik et al., 2023) 42 CT volumes. No MRI or MRA volume from any dataset is used. The four lesion classes in these datasets, both kidney cysts and the primary and nodal gross tumor volumes, are held out. Four datasets report no demographics, and those that do skew male (55 to 63%) and oncologic. We report demographics because a shape representation inherits the shapes of its training cohort. The eight datasets annotate 420 label classes. Merging labels that refer to the same anatomy gives a training vocabulary of 377 anatomical classes. The number of annotated subjects per class varies by more than two orders of magnitude, and Appendix I shows that the model improves as a structure gains training examples. An anatomical class is a segmentation category, so 377 classes are not 

377 separate organs: the vocabulary includes composite tissue and body-region classes inherited from the source datasets, such as muscle , visceral adipose tissue and body trunk ,alongside individual anatomical structures. The released vocabulary lists every class with its subject count and marks the composite classes.

## B EVALUATION PROTOCOL 

Evaluation sets. Each experiment uses a fixed evaluation set, and sets are not pooled. • External benchmarks (Section 5.1, Figure 3, Appendix C): ten benchmarks from datasets that contribute nothing to training. In CT: FLARE22, KiTS23, MSD spleen (Task09) and MSD pan-creas (Task07). In MRI: MSD heart (Task02), MSD hippocampus (Task04) and MSD prostate (Task05). CHAOS contributes three: CT, T1 MRI and T2 MRI. Inputs come from TotalSegmen-tator, AtlasNet and WholeBodySeg on CT and from TotalSegmentator MRI on MRI. 16 Preprint • Method comparison (Section 5.1, Table 1, Appendix P): 90 TotalSegmentator anatomical classes on which all twelve methods were run, all starting from MedSAM predictions. The two ASM variants produce a result for 41 of them. • Held-out WORD and AMOS22 cases (Appendix D): TotalSegmentator and AtlasNet predictions on held-out subject-level test splits, 120 cases, 14 abdominal classes; WholeBodySeg predictions on held-out TotalSegmentator test cases, 104 predicted classes. • Description sensitivity (Appendix E): the WORD and AMOS22 cases and inputs above. • Dataset-level means (Appendix F): 77 anatomical classes on the ToothFairy test split and 145 on the DAP-Atlas test split. • Surface distance and connected components (Appendix F): held-out WORD cases, which provide dense abdominal annotations at native spacing, with MedSAM input. • Identity controls (Appendix G): the ToothFairy test split, the held-out WORD, AMOS22 and TotalSegmentator cases above, and the external benchmarks. • Pure-noise control (Appendix H): about 50 cases from MSD heart and FLARE22 with MedSAM input. • Abnormal kidneys (Section 5.1, Appendix C): the abnormal cases of KiTS23, kidneys that contain tumors, with TotalSegmentator input. • MRI and lesion transfer tasks (Section 5.2): TotalSegmentator MRI predictions on MSD heart, hippocampus and prostate and on the PanSegNet MRI dataset (Zhang et al., 2025); MedSAM input on the seven transfer tasks of Figure 4a, namely the MSD prostate zone, hippocampus, left atrium and brain tumor, the hippocampal tumor task, the pancreatic cysts of Cyst-X (Pan et al., 2025) and, in CT, the pancreatic lesions of PanTS (Li et al., 2025b). • Downstream training (Section 5.3, Appendix L.1): original labels predicted by TotalSegmentator, AtlasNet and WholeBodySeg, corrected labels produced by DART from the same predictions, and held-out reference annotations for evaluation. • Data scaling (Appendix I): 83 anatomical classes. • Vocabulary size and text versus index (Appendix J): the same 500 -case subset of TotalSegmenta-tor, AMOS22 and WORD, so these two experiments are comparable with each other but not with the sets above. 

Reference annotations. Reference annotations are the released annotations of each dataset. DAP-Atlas annotations were created by an automated pipeline and approved through expert review (Jaus et al., 2023). 

Bounding-box prompts for MedSAM. MedSAM is prompted slice by slice with 2D bounding boxes derived from the reference annotation, so the correction methods start from predictions in the right location and the comparison measures shape. DART never sees these bounding-box prompts. It receives MedSAM’s segmentation probabilities, thresholds them at 0.5 to locate its crop, and processes the original probabilities inside the crop, exactly as it does for automatic segmentation models. Because the prompts come from the reference, the extent of this input, and so of DART’s crop, is close to the reference extent. This favours every method that works within its input’s extent, DART included; the automatic inputs of Appendices C and D carry no such information. 

Noise level. For each training class, t∗ is selected on a validation split and then fixed. For a class outside the training vocabulary, t∗ is copied from the structure in which it occurs. No test labels are consulted, and t∗ is not re-selected for any transfer experiment. 

“Up to” values. Unless stated otherwise, “up to” gives the largest per-case gain in the stated evaluation set. Three exceptions are stated where they occur: for the baseline comparison it gives the largest per-class margin over a baseline (Table 10), for the segmentation models of Section 5.3 the largest gain of a single configuration, and for the lesion classes the largest gain in mean Dice of a single task. 

Statistics. For each class in the 90 -class comparison, we compute the per-case paired gain (after DART minus input) and test the null hypothesis of zero mean gain, controlling the false discovery 17 Preprint rate at 5% with the Benjamini–Hochberg procedure. Per-class gains are reported as mean ± standard deviation of the per-case paired gain.

## G IDENTITY CONTROLS 

DART locates its crop by thresholding the input probabilities at 0.5, crops and resizes the original probabilities to 128 3, runs the reverse process, resamples back to the native crop by trilinear inter-polation, and thresholds the result. Resampling and thresholding can change Dice on their own, so two controls run this path without the diffusion model. Identity crops, resizes, resamples and thresh-olds at 0.5, with no noising or denoising. Identity (volume-matched) does the same but chooses the threshold that reproduces the foreground voxel count of the input probabilities thresholded at 0.5,which removes any volume bias of a fixed threshold. On ToothFairy, against a MedSAM input of 53 .83 Dice, the identity control reaches 53 .96 and the volume-matched identity control reaches 54 .00 , while DART reaches 57 .67 . The resampling path therefore accounts for 3.4% of the gain, and the volume bias for 4.4% . On the same split, Gaussian smoothing reaches 54 .12 , a median filter 54 .23 , the convex hull 54 .69 , morphological closing 55 .72 ,and convex hull followed by closing 56 .18 . DART thus exceeds the strongest traditional method by 

1.5 points and the identity control by 3.7 points. Across this evaluation set, the gain is positive on 

652 of 658 class–case pairs. On the held-out WORD and AMOS22 inputs of Appendix D, the same identity control adds 0.06 

Dice points on TotalSegmentator predictions and 0.05 on AtlasNet predictions, and on held-out 22 Preprint TotalSegmentator cases it adds 0.08 on WholeBodySeg predictions, against 2.47 , 1.04 and 3.77 for DART. On the external benchmarks of Appendix C, it adds between 0.02 and 0.24 points, 0.9% to

## H ADDITIONAL OBSERVATIONS 

The opposite control: sampling from pure noise. The identity control removes the diffusion model; this control removes the input. The reverse process starts from pure noise at t = T , in the same crop and under the same description, so the output depends on the description and the crop but not on the probability values within that crop. On about 50 cases from MSD heart (MRI) and FLARE22 (CT) with MedSAM input, the input scores 77 .37 Dice, DART 78 .91 , and sampling from pure noise 34 .08 , or 34 .31 with the threshold chosen to maximise Dice. Because MedSAM is prompted with bounding boxes from the reference annotation, the crop nearly matches the reference extent; even so, the description alone recovers less than half of the input’s Dice. DART therefore edits its input rather than replacing it with a shape generated for the class. 

The baselines are weak on the TotalSegmentator benchmark. Nine of the eleven baselines lower Dice on more than half of the classes they run on (Table 10): the convex hull on 65 of 90 ,SegRefiner on 87 and Post-DAE on all 90 , while the two classical methods that read the image lose 21 .6 and 28 .5 points on average and the two ASM variants about 59 . We re-checked each implementation after observing this. The losses follow from what each method assumes, as the paragraphs below explain, not from implementation errors. 

Fixed rules help some structures and hurt others. The convex hull improves the left autochthon by 2.8 Dice points but lowers the pancreas by 10 .8 and the colon by 7.1: a convex shape suits compact structures and not lobulated or tubular ones. Hole filling barely changes Dice, so the input errors lie at boundaries and in connectivity rather than in interior holes. 

Methods that read the image are unsafe to apply blindly. GMM graph-cut and geodesic active contours work where a strong intensity edge coincides with the anatomical boundary and fail else-where. Over the 90 anatomical classes, their mean gains are −21 .6 and −28 .5 Dice points. Neither can be applied to an unknown structure without first deciding whether it will help. 

Classes without a significant gain. At a 5% false discovery rate, the gain is not significant on six of the 90 anatomical classes: liver ( +0 .01 points), spleen ( +0 .09 ), left scapula ( +0 .15 ), right hip ( +0 .18 ), right kidney ( +0 .18 ) and left kidney ( +0 .30 ). The four organs have inputs above 94 

Dice and leave little to improve. The two bones have low inputs ( 51 .0 and 59 .9 Dice), yet the model changes them little. 

How the gain relates to input quality depends on the input. On the fixed MedSAM input, regressing the per-class gain on input Dice over the 90 anatomical classes gives a slope of −0.003 

(r = −0.03 , p = 0 .78 ), and grouping is more informative than the regression: +2 .5 points on the 59 

anatomical classes below 80 Dice and +0 .8 on the nine above 90 . We attribute the weak relationship to the input itself: bounding-box prompts from the reference annotation raise input Dice unevenly across structures and compress the range, so input quality is a poor proxy for how much shape error remains. On predictions from automatic segmentation models in Appendix D, which receive no such prompts, the relationship is clear: the gain falls as the input improves ( ρ = −0.89 and −0.68 ), both across structures and for the same structure across the two models. The second setting is the one that matches deployment. 

ASM depends strongly on anatomy. On the 41 TotalSegmentator anatomical classes where they produce a result, both ASM variants lower mean Dice by about 59 points. A linear shape space fitted to a few dozen aligned examples cannot represent the variability of hollow and branching structures and pulls the mask toward the mean shape. For thin structures such as the iliac arteries and the subclavian vessels, a small misalignment between that mean shape and the true structure leaves almost no overlap. The two variants differ on only 3 of these 41 anatomical classes. For example, 23 Preprint on the right iliac vein, DART reaches 87 .0 Dice and ASM 6.1, a difference of 80 .9 points. The input is already 84 .7, and morphological closing, the strongest baseline for this class, reaches 86 .1.Thus, the 80 .9-point difference reflects an ASM failure; DART improves the input by 2.3 points and exceeds the strongest baseline by 0.9.

Why the learned baselines fall short. All three are trained on segmentation predictions paired with their reference annotations, so they learn from the kind of errors they are tested on. Post-DAE must reconstruct the whole mask through a compact code, which likely costs detail even where the input is already right; it lowers Dice on every class. SegRefiner reads the image, but it was designed for 2D natural images; applied slice by slice, it lacks 3D context and lowers Dice on 87 of the 90 

classes. The single-pass U-Net shares DART’s backbone and text conditioning but maps its input to the reference annotation in one deterministic forward pass, without diffusion or partial noising. Trained to map a mask that is already close to its reference onto that reference in one step, it learns little more than the identity: it stays within 1.6 Dice points of its input on every class, and on the right adrenal gland it returns its input unchanged on every case (per-case gain 0.0 ± 0.0 in Table 1). DART instead adds noise first, which turns the input into a noisy sample of the form seen in training and lets the model make larger changes of shape.

Figure 5 (Section 5.4) retrains the model on nested subsets with 10% to 100% of each structure’s training probability maps, keeping everything else fixed, and evaluates 83 anatomical classes. We see two reasons for the low-data points, where the output falls below the input. With few training examples, the learned distribution is a coarse model of the structure. And t∗ is held at the values chosen for the full model, so a weak model may change a prediction as much as a strong one. Together they can pull a mask toward an inaccurate shape. With more training examples, the learned shape representation improves, and correction at the same noise level becomes useful. ## M BASELINE METHODS 

Correction methods start from the predictions of the same upstream segmentation model for each structure and return binary masks. DART receives segmentation probabilities; methods that need a binary input use the corresponding thresholded mask. On the TotalSegmentator benchmark the upstream model is MedSAM; on the external benchmarks it is an automatic segmentation model. No method sees test labels. Hyperparameters are selected per class on the validation split by grid search over the ranges below and then applied unchanged to the test cases, in the same way as t∗ for DART. Morphological closing, the strongest single traditional method on ToothFairy (Appendix G), is also run on the held-out WORD and AMOS22 inputs of Appendix D with the same per-class sweep. 

Learned methods. All three are trained on segmentation predictions paired with their reference annotations, with the same subject-level splits as DART. The single-pass U-Net (Ronneberger et al., 2015) uses DART’s backbone and text conditioning and receives the same thresholded prediction as the other correction baselines, but maps it to its reference annotation in one deterministic forward pass, without diffusion or partial noising. It tests whether a single forward pass is enough. Post-DAE 

(Larrazabal et al., 2020) is a denoising autoencoder that maps an implausible mask to a plausible one; we reimplement it in 3D. SegRefiner (Wang et al., 2023) adjusts a coarse mask with a discrete diffusion process conditioned on the image, trained on the same pairs. It was designed for 2D images, so we apply it slice by slice, with the image. 

Traditional methods: morphology and connected components. These use only the mask. Mor-phological operations use a ball-shaped structuring element with radius swept over {1, 2, 3, 4, 5}

voxels. Hole filling (Soille, 2004) fills all background components not connected to the volume bor-der and has no parameters. Morphological closing (Serra, 1983) is a dilation followed by an erosion. 

Largest component (He et al., 2009) keeps the largest 26-connected component, which is only valid 27 Preprint for structures that form a single component. Convex hull (Barber et al., 1996) replaces the mask by its 3D convex hull. 

Traditional methods: statistical shape models. Both are fitted on the training split and applied by projection. Shapes are signed distance functions on a fixed grid, rigidly aligned to a per-class mean. The number of modes is swept over {5, 10 , 20 , 50 } or chosen to explain 95% of variance. 

ASM (Cootes et al., 1995) projects the shape onto the leading modes. Robust ASM (Rogers & Gra-ham, 2002) uses a trimmed least-squares fit that down-weights outlying boundary points, with trim-ming fraction swept over {0.1, 0.2, 0.3}. Both produce a result for 41 of the 90 TotalSegmentator anatomical classes. 

Traditional methods: image-based. These two methods, like SegRefiner, read image intensity; the remaining correction baselines, including the single-pass U-Net, and DART use segmentation predictions without the image. We include them because a practitioner would try them first. GMM graph-cut (Rother et al., 2004) runs iterative graph-cut segmentation with Gaussian mixture appear-ance models, five components per mixture and three iterations. Geodesic active contour (Caselles et al., 1997) evolves an edge-based contour, with balloon force swept over {− 1, 0, 1} and iteration budget over {25 , 50 , 100 , 200 }.

Additional baselines on the external benchmarks. On the external benchmarks, the comparison extends the learned and traditional methods above with opening, dilation, erosion, opening followed by closing, 2D hole filling, removal of small components, Gaussian, median and signed-distance smoothing, a 2D convex hull, a mean-shape and a PCA signed-distance shape model, Chan–Vese and random walker segmentation, and the identity control of Appendix G. Each is tuned per class on the validation split. Figure 3 shows the two strongest for each structure. Unless stated otherwise, baselines use scikit-image (van der Walt et al., 2014), SciPy (Virtanen et al., 2020) and SimpleITK on the stated input representations and identical hardware. 

## N CORPUS -S CALE ANNOTATION AND RELEASE 

We run the pipeline on 45 ,000 CT scans assembled from the public datasets catalogued by Rokuss et al. (2026). The pipeline has three stages. The same predict-then-correct design has been used to assemble large annotated collections with limited human review (Li et al., 2025a). 

Stage 1: prediction by a suite of specialist models. These scans have no reference annotations, so MedSAM with bounding-box prompts from the reference is not available. Instead we predict each structure with the published segmentation model that covers it best. The suite comprises the TotalSegmentator task models (Wasserthal et al., 2023), VISTA3D (He et al., 2024), the DAP-Atlas pipeline (Jaus et al., 2023) and further published whole-body and organ-specific models, together with MedSAM (Ma et al., 2024a) on the ToothFairy structures, where reference boxes are available. Models were assigned to structures by coverage of the structure, the modality and field of view of the scan, and reported performance on that structure; where more than one model covered a structure, the assigned model’s prediction was used without fusion. The full structure-to-model assignment table is released with the annotations. Most scans cover only part of the body, so each contributes far fewer classes than the vocabulary holds. 

Stage 2: correction. DART corrects each predicted probability map with that class’s description and its fixed t∗, with no retuning for the corpus. The resulting corrected masks serve as training labels. 

Stage 3: distillation and release. DART-Seg, a free-text promptable 3D segmentation model with the architecture of Rokuss et al. (2026), is trained on the corrected training labels and applied across the corpus to produce the released annotations (Figure 12). Like DART, DART-Seg names classes with text, so a large vocabulary needs no equally large output layer. The released annotations are therefore the output of DART-Seg. 28 Preprint 

Figure 12: Architecture of DART-Seg (Rokuss et al., 2026). Left: a frozen text encoder embeds a text prompt naming the target structure, and a trainable Prompt Decoder produces text features that modulate the image decoder. Right: at each decoder level, upsampled features are concatenated with the encoder skip connection and modulated by the text features before the segmentation head, with deep supervision at every level. We use the architecture unmodified and train it on DART-corrected training labels. 

Compute. DART takes 0.59 s per probability map on one AMD MI250X GPU at 128 3. The corpus pipeline took about two thousand GPU-hours on AMD MI250X GPUs, and training the model, including the scaling and conditioning experiments, a few hundred more. 

Quality audit. We drew a uniform random sample of 10 ,000 of the 45 ,000 scans and split it into five disjoint blocks of 2,000 , one per reader. For each scan, the reader saw the annotation with a written annotation guideline for each structure present, and marked the scan as passing if every structure followed its guideline. 98 .5% of scans passed, with a binomial standard error below 0.2

percentage points. Automated critics offer a complementary route to flagging label errors in released collections (Bassi et al., 2025b). 

Release. We release the annotations for the 45 ,000 scans, together with the vocabulary, the de-scription used for every class, the per-class t∗ and the structure-to-model assignment table, so that the annotations can be regenerated and audited independently. The source datasets carry different licences, several of them non-commercial or share-alike, so DART-45K is released as an annotation layer for each source dataset under that dataset’s own terms.
